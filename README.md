## Recommended GitHub workflow

1. Go to the Academic Pages template: `https://github.com/academicpages/academicpages.github.io`
2. Click `Use this template`, then create a repository named `YOUR-GITHUB-USERNAME.github.io`.
3. Upload/replace these customized files and folders in that repository:
   - `_config.yml`
   - `_data/navigation.yml`
   - `_pages/`
   - `_publications/`
   - `_projects/`
   - `images/`
   - `files/`
4. In `_config.yml`, replace:
   - `YOUR-GITHUB-USERNAME`
   - `YOUR-GITHUB-USERNAME/YOUR-GITHUB-USERNAME.github.io`
5. Add your portrait image as `images/profile.png`.
6. In GitHub, open `Settings > Pages` and publish from the `main` branch.

## Files you will edit most often

- `_pages/about.md`: homepage text
- `_pages/cv.md`: CV content
- `_publications/*.md`: one file per publication
- `_projects/*.md`: one file per project
- `_data/news.yml`: news items shown below the sidebar profile
- `_includes/author-profile.html`: sidebar profile and news layout
- `_config.yml`: name, email, sidebar profile, and site URL

The saved Wix files are kept only as reference and are excluded from the Jekyll build.
